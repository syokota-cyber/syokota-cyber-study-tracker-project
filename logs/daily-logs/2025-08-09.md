## 🔍 問題の根本原因分析

### **依存関係管理の課題**
```yaml
# serverless.yml の設定
custom:
  pythonRequirements:
    dockerizePip: non-linux
    requirementsFile: requirements-lambda.txt
    layer:
      name: python-deps
      description: Python dependencies for study-tracker-api
```

### **推定される原因**
1. **Lambdaレイヤーのビルド失敗**: PyJWTライブラリのコンパイルエラー
2. **アーキテクチャ不一致**: ローカル環境とLambda環境の差異
3. **依存関係の競合**: 他のライブラリとの競合
