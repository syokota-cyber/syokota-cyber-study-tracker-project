### **CloudFront → Lambda のパス転送問題**
```
ブラウザ: OPTIONS /api/v1/study-records
CloudFront: /api/v1/study-records → /dev/api/v1/study-records
Lambda: /dev/api/v1/study-records の解析で404
```

### **Lambda関数のパス解析ロジック**
```python
# 現在のコード（問題あり）

    path_parts = path_parts[1:]  # dev を除去
elif len(path_parts) >= 3 and path_parts[0] == 'api' and path_parts[1] == 'v1':
    pass
```
