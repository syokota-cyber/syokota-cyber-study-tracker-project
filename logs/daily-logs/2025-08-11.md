## 🚨 本日の失敗と学び

### 1. Lambda関数のFormData対応での連続エラー

#### エラー1: 500 Internal Server Error
**発生時刻**: 午前中
**原因**: Lambda関数のデプロイ問題
**解決策**: `serverless remove && serverless deploy`
**学び**: 完全な再デプロイの重要性

#### エラー2: 400 Bad Request（FormData処理）
**発生時刻**: 午前中
**原因**: API Gatewayでヘッダー名が小文字に変換される問題
**解決策**: Content-Typeヘッダーの両方のケースに対応
**学び**: API Gatewayの仕様理解の重要性

#### エラー3: CloudFront 500エラー
**発生時刻**: 午前中
**原因**: CloudFrontのAPI Gateway URL設定が古いまま
**解決策**: CloudFront設定の更新
**学び**: インフラ設定の連携確認の重要性

#### エラー4: フロントエンド400エラー
**発生時刻**: 午前中
**原因**: FormDataのContent-Type設定不備
**解決策**: URLSearchParamsとContent-Typeヘッダーの明示的設定
**学び**: フロントエンド・バックエンド間のデータ形式統一

#### エラー5: UI崩れ
**発生時刻**: 午前中
**原因**: CSSレイアウト競合
**解決策**: main.cssのレイアウト修正
**学び**: グローバルCSSとコンポーネントCSSの競合回避

#### エラー6: 強制リダイレクト問題
**発生時刻**: 午前中
**原因**: 認証状態の初期化処理不備
**解決策**: isAuthenticatedの初期値をnullに変更
**学び**: Vue.jsの状態管理の適切な初期化

### 2. リセットの決断

## 🔧 技術的学び

- **ヘッダー処理**: API Gatewayでヘッダー名が小文字に変換される
- **デプロイ**: 完全な再デプロイが必要な場合がある
- **ログ確認**: `serverless logs -f api --tail`の重要性
