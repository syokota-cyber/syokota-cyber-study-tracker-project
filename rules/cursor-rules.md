## 🚨 **重要な開発プロセスルール**

### 段階的開発・確認の原則
**⚠️ 絶対に守るべきルール**

1. **ローカル開発完了確認**
   - コードが正常に動作することを確認
   - テストが通ることを確認
   - エラーが発生しないことを確認
   - ユーザビリティが確認済みであることを確認

2. **テスト環境での動作確認**
   - **絶対にスキップしてはいけない手順**
   - API Gatewayの動作確認
   - Lambda関数の動作確認
   - DynamoDBとの連携確認
   - フロントエンドの表示確認
   - 認証機能の動作確認
   - エラーハンドリングの確認

3. **本番環境デプロイ**
   - テスト環境での確認完了後にのみ実行
   - 段階的なデプロイを実施
   - 各段階で確認を取る

### 禁止事項
- ❌ **ローカル確認なしでのデプロイ**
- ❌ **テスト環境確認なしでの本番デプロイ**
- ❌ **大きな変更の一括デプロイ**
- ❌ **確認なしでの自動デプロイ**
- ❌ **エラーが発生している状態でのデプロイ**

## 🔄 開発フロー

### 1. ローカル開発フェーズ
```bash
# バックエンド開発
cd src
python -m uvicorn api.main:app --reload --host 127.0.0.1 --port 8000

# フロントエンド開発
cd study-tracker-frontend
npm run dev
```

### 2. テスト環境デプロイフェーズ
```bash
# バックエンド（Lambda）のテスト環境デプロイ
serverless deploy --stage dev

# フロントエンドのテスト環境ビルド
cd study-tracker-frontend
npm run build
```

### 3. 本番環境デプロイフェーズ
```bash
# バックエンド（Lambda）の本番環境デプロイ
serverless deploy --stage prod

# フロントエンドの本番環境デプロイ
cd study-tracker-frontend
npm run build
aws s3 sync dist/ s3://learninggarden.studio --delete
aws cloudfront create-invalidation --distribution-id E3RTAE75MJ0MSH --paths "/*"
```

## 🚨 **エラーログ管理ルール**

### エラーログ記録の義務
**⚠️ 絶対に守るべきルール**

1. **エラー発生時の即座記録**
   - エラーメッセージの完全な記録
   - 発生時刻の記録
   - エラー発生時の状況記録
   - 関連ファイルの特定

2. **解決過程の記録**
   - 試行した解決策の記録
   - 成功した解決策の詳細記録
   - 解決に要した時間の記録
   - 技術的学びの記録

3. **再発防止策の記録**
   - エラーの根本原因分析
   - 再発防止策の提案
   - 類似エラーの関連付け
   - ベストプラクティスの更新

### エラーログ記録場所
```
logs/error-logs/
├── README.md                    # 管理システム説明
├── index.md                     # 時系列インデックス
└── YYYY-MM-DD-error-summary.md  # 日別エラーサマリー
```

### エラーログ記録形式
```markdown
## 🚨 エラー詳細
**発生時刻**: YYYY-MM-DD HH:MM
**エラーメッセージ**: 完全なエラーメッセージ
**原因分析**: 技術的な原因の詳細
**解決策**: 具体的な解決手順
**関連ファイル**: 影響を受けたファイル一覧
**タグ**: #エラー種別 #技術領域 #機能領域
```

### よくあるエラーと解決策の標準化
1. **500エラー（Lambda関数）**
   ```bash
   serverless remove && serverless deploy
   ```

2. **400エラー（FormData処理）**
   ```typescript
   content_type = headers.get('content-type', headers.get('Content-Type', '')).lower()
   ```

3. **UI崩れ（CSS競合）**
   ```css
   #app { width: 100%; min-height: 100vh; }
   ```

4. **リダイレクト問題（認証状態）**
   ```typescript
   const isAuthenticated = ref<boolean | null>(null)
   ```
